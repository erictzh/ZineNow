# Shared parts

Some small pieces of code are used by several apps, so they live once in the `shared/` folder: number boxes with − and + buttons, the Display gear, the "Source code" link, picture dropping, the leave-page warning, saving by download, and touch support. They are described here because the same behaviour shows up everywhere.
