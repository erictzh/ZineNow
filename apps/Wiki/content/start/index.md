# Start here

**ZineNow** is a small suite of tools for making zines (little handmade booklets) that all run **inside your web browser**: nothing to install, no account, no server, and (apart from AI model downloads you choose to make) nothing leaves your device. This wiki is a textbook for the whole suite: how to use each tool, how it works, and the real code behind it.

How to read it:
- Each page has four parts: **Intro** (what it is), **How to use** (what to click), **How it works** (the technique, with its proper names) and **Code** (the real functions, with file path and line numbers, each followed by a line-by-line walkthrough called **The Logic** and, for calculations, a **Worked example**).
- Words you may not know are explained the first time they appear, and collected in the [Glossary](appendix/glossary).
- Use the search box, or the Previous/Next buttons under each page.

This chapter covers what the suite is, how it is built and runs offline, and the small shared parts every app uses.
