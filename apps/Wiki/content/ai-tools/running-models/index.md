# Running models in the browser

The AI tools work without any server: the model is a file your browser keeps and a program called a **runtime** runs it. These pages explain how.

- [ONNX Runtime Web, WebGPU and WASM](ai-tools/running-models/onnx-runtime): the engine that runs the models, on the graphics chip or the processor.
- [The opt-in download flow](ai-tools/running-models/download-flow): how models are fetched, kept in the **Cache API**, counted and deleted.
- [Model list and licences](ai-tools/running-models/model-list-licences): every model, who made it, how open it is, and the rules for adding one.
